# Center for Educative and Humanitarian Initiatives Website

Static GitHub Pages website built with pure HTML, CSS, and JavaScript.

## Files

- `index.html` — About Us / homepage
- `projects.html` — Projects
- `events.html` — Events
- `contact.html` — Contact
- `style.css` — site styling
- `script.js` — mobile navigation and placeholder action
- `assets/cehi-logo.png` — organization logo

## GitHub Pages

Upload all files and folders to the repository root. GitHub Pages will use `index.html` as the homepage.
